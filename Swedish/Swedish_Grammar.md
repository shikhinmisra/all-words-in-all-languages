# LEVEL 1: ABSOLUTE BASICS

## Lesson 1: Alphabet and pronunciation

Swedish has 29 letters: A–Z plus **å, ä, ö**. Stress is usually on the first syllable.

### Vowels

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| a — *tak* | "ah" as in *father* (roof) |
| e — *se* | like "ee/ay", similar to *say* without the glide (see) |
| i — *bil* | "ee" as in *see* (car) |
| o — *bo* | usually "oo" as in *moon* (live) |
| u — *hus* | no English equivalent: a tight, rounded "ew" (house) |
| y — *ny* | "ee" said with rounded lips, like German *ü* (new) |
| å — *gå* | "o" as in *more* (go) |
| ä — *här* | "e" as in *bed* / "ai" as in *air* (here) |
| ö — *öl* | "u" as in *fur*, without the r (beer) |

### Long and short vowels

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| tak (one consonant after the vowel) | long vowel: roof |
| tack (double consonant after the vowel) | short vowel: thanks |
| vit | long: white |
| vitt | short: white (ett-form) |

### Special consonant sounds

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| g + e, i, y, ä, ö — *göra* | "y" as in *yes* (do) |
| k + e, i, y, ä, ö — *köpa* | soft "ch"/"sh" sound (buy) |
| sj, skj, stj, sk + e, i, y, ä, ö — *sjö, skjorta, stjärna, sked* | the Swedish "sj-sound", a breathy "hw/sh" (lake, shirt, star, spoon) |
| tj, kj — *tjugo, kjol* | soft "ch" (twenty, skirt) |
| j, dj, gj, hj, lj — *ja, djur, gjorde, hjälp, ljus* | "y" as in *yes* (yes, animal, did, help, light) |
| rs — *mars, först* | "sh" (March, first) |
| rt, rd, rn, rl — *kort, bord* | r blends into the next letter (card, table) |

## Lesson 3: The verbs *vara* (to be) and *ha* (to have)

Swedish verbs have **one present-tense form for every person**.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| att vara | to be |
| jag är | I am |
| du är | you are |
| han / hon är | he / she is |
| vi är | we are |
| ni är | you (plural) are |
| de är | they are |
| att ha | to have |
| jag har | I have |
| hon har | she has |
| vi har | we have |
| Jag är glad. | I am happy. |
| Hon har en katt. | She has a cat. |

---

## Lesson 4: Present tense

To form the present tense, add **-r** to the infinitive. If the infinitive ends in **-a** after a consonant, many verbs replace the **-a** with **-er**. The form is the same for every person.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| tala → talar | speak → speak(s) |
| arbeta → arbetar | work → work(s) |
| bo → bor | live → live(s) |
| tro → tror | believe → believe(s) |
| skriva → skriver | write → write(s) |
| läsa → läser | read → read(s) |
| höra → hör *(stem ends in -r: no -er)* | hear → hear(s) |
| Jag talar svenska. | I speak Swedish. / I am speaking Swedish. |
| Du talar svenska. | You speak Swedish. |
| Han talar svenska. | He speaks Swedish. |
| De talar svenska. | They speak Swedish. |

> Swedish has no "-ing" form. *Jag läser* = "I read" **and** "I am reading".

## Lesson 6: Negation with *inte*

In a main clause, **inte** comes **after the verb**.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| Jag är inte trött. | I am not tired. |
| Hon talar inte franska. | She does not speak French. |
| Vi har inte en bil. | We do not have a car. |
| Jag kan inte simma. | I cannot swim. |
| Han dricker aldrig kaffe. | He never drinks coffee. |

> Swedish has no "do/does" helper: *Jag talar inte* = "I do not speak".

## Lesson 7: Yes/no questions

Put the **verb first**.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| Du talar svenska. → Talar du svenska? | You speak Swedish. → Do you speak Swedish? |
| Är du trött? | Are you tired? |
| Har ni barn? | Do you have children? |
| Kan du simma? | Can you swim? |
| Ja. | Yes. |
| Nej. | No. |
| Jo! *(answer to a negative question)* | Yes! (contradicting "not") |
| Talar du inte svenska? – Jo, det gör jag. | Don't you speak Swedish? – Yes, I do. |
| Ja, det gör jag. | Yes, I do. |
| Nej, det gör jag inte. | No, I don't. |
| Ja, det är jag. | Yes, I am. |
| Ja, det har jag. | Yes, I have. |
| Ja, det kan jag. | Yes, I can. |

# LEVEL 2: NOUNS

## Lesson 10: Two genders, *en* and *ett*

Every noun is either an **en-word** (about 75% of nouns) or an **ett-word**. Always learn the noun together with its article.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| en bil | a car |
| en katt | a cat |
| en flicka | a girl |
| en dag | a day |
| en bok | a book |
| ett hus | a house |
| ett barn | a child |
| ett äpple | an apple |
| ett bord | a table |
| ett år | a year |

---

## Lesson 11: "The": definite singular

There is no separate word for "the". Add an ending instead: **en-words + -en / -n**, **ett-words + -et / -t**.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| en bil → bilen | a car → the car |
| en flicka → flickan | a girl → the girl |
| en dag → dagen | a day → the day |
| ett hus → huset | a house → the house |
| ett äpple → äpplet | an apple → the apple |
| ett bord → bordet | a table → the table |

---

## Lesson 12: Plural, the five groups

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| **Group 1: -or** (en-words ending in -a) | |
| en flicka → flickor | a girl → girls |
| en klocka → klockor | a clock → clocks |
| en gata → gator | a street → streets |
| **Group 2: -ar** (many en-words, often one syllable or ending in -e) | |
| en bil → bilar | a car → cars |
| en dag → dagar | a day → days |
| en pojke → pojkar | a boy → boys |
| **Group 3: -er** (often loanwords stressed on the last syllable) | |
| en park → parker | a park → parks |
| en student → studenter | a student → students |
| en restaurang → restauranger | a restaurant → restaurants |
| **Group 4: -n** (ett-words ending in a vowel) | |
| ett äpple → äpplen | an apple → apples |
| ett frimärke → frimärken | a stamp → stamps |
| **Group 5: no ending** (ett-words ending in a consonant; en-words ending in -are) | |
| ett hus → hus | a house → houses |
| ett barn → barn | a child → children |
| en lärare → lärare | a teacher → teachers |

## Lesson 18: Compound nouns

Words join together. The **last part decides the gender**. Sometimes **-s-** is added, or a final **-a** becomes **-u / -o** or disappears.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| sjuk + ett hus → ett sjukhus | sick + house → a hospital |
| tand + en borste → en tandborste | tooth + brush → a toothbrush |
| barn + en bok → en barnbok | child + book → a children's book |
| arbete + en dag → en arbetsdag | work + day → a working day |
| flicka + en vän → en flickvän | girl + friend → a girlfriend |
| gata + ett kök → ett gatukök | street + kitchen → a snack bar |
| kyrka + en gård → en kyrkogård | church + yard → a cemetery |

## Lesson 22: Adjectives before a noun (indefinite)

**en-word: base form**; **ett-word: + t**; **plural: + a**.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| en stor bil | a big car |
| ett stort hus | a big house |
| stora bilar / stora hus | big cars / big houses |
| en röd bil / ett rött hus / röda bilar | a red car / a red house / red cars |
| en ny bok / ett nytt år / nya böcker | a new book / a new year / new books |
| en vit katt / ett vitt hus / vita katter | a white cat / a white house / white cats |
| en rolig film / ett roligt spel / roliga filmer | a fun film / a fun game / fun films |
| en bra film / ett bra hus / bra filmer | a good film / house / films (*bra* never changes) |

> Spelling: stressed vowel → **-tt** (ny → nytt, blå → blått); **-d** after a vowel → **-tt** (röd → rött, god → gott); **-t** after a consonant → no change (svart → svart).

## Lesson 31: The V2 rule (verb always in second place)

This is the **most important word-order rule**. The verb is always the second element. If anything other than the subject comes first, the subject moves **after** the verb.

| stulen – stulet – stulna *(group 4)* | stolen |
| en målad vägg / ett målat hus / målade väggar | a painted wall / a painted house / painted walls |
| det stängda fönstret | the closed window |
| Jag har skrivit brevet. *(supine)* | I have written the letter. |
| Brevet är skrivet. *(participle)* | The letter is written. |
| ställa in → Mötet är inställt. | cancel → The meeting is cancelled. |
| stänga av → Telefonen är avstängd. | turn off → The phone is turned off. |

> With particle verbs, the particle becomes a **prefix** in the participle.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| spännande | exciting |

## Lesson 60: Reported speech

After a past-tense verb like *sa* or *frågade*, the tense shifts back.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| "Jag är trött", säger han. → Han säger att han är trött. | "I'm tired," he says. → He says that he is tired. |
| "Jag är trött", sa han. → Han sa att han var trött. | "I'm tired," he said. → He said that he was tired. |
| "Jag har ätit." → Hon sa att hon hade ätit. | "I have eaten." → She said that she had eaten. |
| "Jag ska komma." → Han sa att han skulle komma. | "I will come." → He said that he would come. |
| "Är du hungrig?" → Hon frågade om jag var hungrig. | "Are you hungry?" → She asked if I was hungry. |
| "Var bor du?" → Han frågade var jag bodde. | "Where do you live?" → He asked where I lived. |

## Lesson 62: Object shift (pronoun before *inte*)

When the verb is simple and there is no particle, an unstressed **pronoun** object moves **before** *inte*. A noun stays after *inte*.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| Jag känner honom inte. | I don't know him. |
| Jag känner inte Peter. | I don't know Peter. |
| Jag ser den inte. | I don't see it. |
| Jag har inte sett honom. *(helping verb: no shift)* | I haven't seen him. |
| Jag tycker inte om honom. *(particle verb: no shift)* | I don't like him. |

## Lesson 67: Emphasis by fronting

Any element can go first to show emphasis. The V2 rule still applies.

| 🇸🇪 Svenska | 🇬🇧 English |
| --- | --- |
| Den filmen har jag sett. | That film I have seen. |
| Det vet jag inte. | That I don't know. / I don't know (that). |

| Om du vill, så kan vi gå. *(spoken: så after an if-clause)* | If you want, (then) we can go. |
